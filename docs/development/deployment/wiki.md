# The wiki (/wiki)

A [Gollum](https://github.com/gollum/gollum) wiki served from a git repo, at `/wiki` on
whichever game server runs it — no extra domain or DNS. Part of it is generated from
`game-data/`; the rest is written by hand.

## How it fits together

```
game-data/*.json ──(codex --wiki <checkout>)──▶ wiki repo (bare) ──▶ Gollum :4567 ──▶ game server /wiki/*
                                                     ▲                  (--base-path wiki)   (config.yml wiki.url)
                                  hand-written pages (git push, or Gollum's editor)
```

- **Generated pages** — `Items/`, `Monsters/`, `Spells/`, `Locations/`, `NPCs/`,
  `Rules/`, their index pages (`Items.md`, …) and `media/` (sprites copied from
  `www/res/img/`). Every generated page starts with the marker line
  `<!-- generated by codex --wiki … -->`. The generator rewrites those on each run and
  deletes the ones whose data is gone, so **edits to a generated page are lost**.
- **The theme** — `custom.css` and `custom.js` (loaded by `gollum --css --js`) are
  generated too, from `cmd/codex/wiki/theme.css` and `theme.js`. They carry the game's
  six themes under the same token names (`--color-bgPrimary`, …), map Gollum's Primer
  variables onto them, and add the game's header. Being on the game's origin, the wiki
  reads the player's `preferred-theme`, and picking a theme in either place changes
  both. Style changes go in those two files, not in the wiki.
- **Hand-written pages** — anything without the marker: `Home.md`, `_Sidebar.md`,
  guides, lore. The generator seeds `Home.md` and `_Sidebar.md` once if they're
  missing, then never touches them again. Hand pages can live anywhere, even inside a
  generated folder.
- Pages are named by **id** (`Items/longsword`) so links survive a rename; Gollum's
  `--h1-title` shows the first `# Heading` as the title. Link to a generated page with
  `[[Longsword|/Items/longsword]]`.
- Quests, POIs and encounter drafts are deliberately left out (spoilers, and still drafts).

## Publishing

Every push to `main` runs the **Publish wiki** step in `deploy-test.yml`: clone the
wiki repo, run `./codex -wiki`, commit as "Pubkey Quest", push. If someone edited the
wiki in between, it resets onto their commit and regenerates. It's non-blocking and
skipped until the wiki repo exists. The repo path is the `WIKI_REPO` Actions variable
(default `/home/pubkey-test/wiki.git`).

Images are written as raw `<img>` tags, which Gollum doesn't prefix, so the generator
needs the base path: `-wiki-base` (default `/wiki`).

### Run it locally

```bash
go run ./cmd/codex --wiki ../pubkey-quest-wiki
git -C ../pubkey-quest-wiki init -b main && git -C ../pubkey-quest-wiki add -A && git -C ../pubkey-quest-wiki commit -m wiki
docker run --rm -p 127.0.0.1:4567:4567 -v "$PWD/../pubkey-quest-wiki:/wiki" gollumwiki/gollum:6.1.0 --ref main --base-path wiki --h1-title --css --js
```

Add `wiki: { url: "http://127.0.0.1:4567" }` to `config.yml`, start the server, and open
`http://localhost:8585/wiki/`. Gollum serves what's **committed** — re-run the generator
and commit to see changes.

## One-time setup on the test host

1. **Create the repo** as the runner's user (the same user must own it — git refuses
   repos owned by someone else):
   ```bash
   git init --bare -b main /home/pubkey-test/wiki.git
   ```
   The next push to `main` fills it.
2. **Install Docker** and add that user to the `docker` group.
3. **Install the service** from `wiki.service.template`: set `USER`, and `UID:GID` to
   that user's `id -u`:`id -g`. Then:
   ```bash
   sudo cp wiki.service /etc/systemd/system/pubkey-wiki.service
   sudo systemctl daemon-reload && sudo systemctl enable --now pubkey-wiki
   ```
4. **Point the game server at it** in the service directory's `config.yml`, then
   restart the server:
   ```yaml
   wiki:
     url: "http://127.0.0.1:4567"
   ```
   `/wiki` is public: it skips sign-in, and stays reachable while `launch.closed` is on.

## Editing

The service starts with `--no-edit`: the web editor is off, and pages change only by
pushing to the wiki repo. **Gollum has no accounts**, so before dropping `--no-edit`
put authentication in front of it — the `/wiki` route in the game server
(`cmd/server/routes/wiki.go`) is the natural place, since it already knows who's signed in. Otherwise
anyone on the internet can rewrite it.
